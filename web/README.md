# grut Website

The marketing and documentation site for [grut](../README.md), built with [Astro](https://astro.build).

## Development

```bash
cd web
npm install
npm run dev      # Start dev server at localhost:4321
npm run build    # Build for production
npm run preview  # Preview production build
```

## Deployment

The site is deployed automatically via the `deploy-web.yml` GitHub Actions workflow.
